# Repo-level agent skills

This directory is reserved for crucial CausalPy practice that does not belong in `AGENTS.md` or `ARCHITECTURE.md`.

Do not add a skill for a generic maintainer workflow. Issue triage, pull-request review, planning, environment setup, and CI greening belong in a developer's own user-level agent skills.

A skill belongs here only when the practice is specific to this repository, changes an agent's decisions, and is a poor fit for `AGENTS.md` or `ARCHITECTURE.md`. There are currently no such skills.

User-facing skills that teach agents how to use CausalPy live in `causalpy/skills/`. Leave those alone when changing maintainer workflow.
